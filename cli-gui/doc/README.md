# CLI GUI Docs

This directory owns the CLI GUI product, design, architecture, and planning documents for the standalone local Web app under `cli-gui/`.

## Canonical Documents

- `cli-gui-design.md`: durable design notes and current design follow-ups.
- `prd-cli-gui.md`: MVP01 product requirements.
- `prd-cli-gui-workbench.md`: three-column workbench product requirements.
- `spec-cli-gui-workbench.md`: workbench architecture and implementation specification.
- `cli-gui.md`: original Product AI OS MVP01 draft.
- `bugrail-idea.md`: current exploratory UI/theme notes.
- `todo.md`: current local CLI GUI todo notes.
- `AGENTS.md` and `cli-gui-agent.md`: CLI GUI documentation and UI-delivery operating notes.
