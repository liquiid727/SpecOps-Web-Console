# CI Governance Baseline

Use this skill to standardize change-validation and Git readiness checks.

## Workflow

1. Read `references/change-validation.md`.
2. Read `references/stage-scope.md`.
3. Read `references/ci-record.md`.
4. Output one evidence-based CI readiness summary.

## Non-Goals

- hardcoding one repository's commit-message style
- replacing repository-specific merge policy
