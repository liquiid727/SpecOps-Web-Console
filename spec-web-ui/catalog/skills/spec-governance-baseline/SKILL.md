# Spec Governance Baseline

Use this skill for cross-project spec governance.

## Workflow

1. Read `references/direction-and-execution.md`.
2. Read `references/truth-boundaries.md`.
3. Read `references/reviewer-gates.md`.
4. Output the required design artifacts and review expectations.

## Non-Goals

- promoting draft design directly into runtime truth
- coupling spec governance to one repository's module map
