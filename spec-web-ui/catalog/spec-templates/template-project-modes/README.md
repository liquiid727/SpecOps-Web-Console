# Project Modes

This project supports three operating modes:

- `LiteSpec`
- `GoalSpec`
- `EnterpriseSpec`

Start from `LiteSpec`.

Move to `GoalSpec` when the team wants a standing six-step goal loop (prd -> prd-to-spec -> to-issues -> goal -> review-it -> ship-it) with explicit review and ship gates.

Move to `EnterpriseSpec` when QA, audit, release evidence, security review, or multi-team coordination becomes a first-class delivery requirement.
