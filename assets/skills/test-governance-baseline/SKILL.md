# Test Governance Baseline

Use this skill to standardize test planning and reporting.

## Workflow

1. Read `references/track-selection.md`.
2. Read `references/test-artifacts.md`.
3. Read `references/coverage-and-risks.md`.
4. Output a stable Test Plan and Test Report shape.

## Non-Goals

- declaring one universal coverage percentage for every repository
- replacing repository-specific test assets or environment setup rules
