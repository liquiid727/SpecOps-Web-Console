# Spec Template Catalog

Spec template assets for the SpecOS web UI belong here.

Each template asset can provide an `asset.json` manifest so the tool site can render it without treating a target project directory as the source of truth.

The primary template surfaces are:

- requirement package templates under `.requirements/templates/`
- platform design under `design/_template/`
- project mode guidance under `docs/spec-modes/`
- Go engineering-pack templates under `ai/templates/`
