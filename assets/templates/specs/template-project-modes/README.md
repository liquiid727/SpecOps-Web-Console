# Project Modes

This project supports three operating modes:

- `LiteSpec`
- `GoalSpec`
- `EnterpriseSpec`

Start from `GoalSpec`.

Move to `GoalSpec` when the team wants an approved Feature Spec to branch into implementation Issues and an independent, version-bound Test Spec before explicit review and ship gates.

Move to `EnterpriseSpec` when QA, audit, release evidence, security review, or multi-team coordination becomes a first-class delivery requirement.
