# GoalSpec Overlay: Testing Agent

- Run `/review-it` against the issue's feature-local `tests.md`; do not require enterprise-style categorized test directories.
- Verify the change is traceable to the originating issue in `specs/issues/` before signing off.
- Escalate to `EnterpriseSpec`-style categorized evidence only when the feature's risk clearly outgrows a single review pass.
