# GoalSpec Overlay: Implementation Agent

- Take one issue from `.features/issues/` per `/goal` run and implement it end to end inside `.features/RP-xxx/`.
- Record the changed-surface summary in `implementation/` so `/review-it` and `/ship-it` can trace the change back to its issue.
- Do not start a second issue before the current one has a handoff note; the loop is one issue at a time, not a batch.
