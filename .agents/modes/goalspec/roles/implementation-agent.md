# GoalSpec Overlay: Implementation Agent

- Take one issue from `.requirements/requirements/R0NN-<slug>/issues.md` per `/goal` run and implement it end to end inside `.requirements/requirements/R0NN-<slug>/`.
- Record the changed-surface summary in the issue's `### Completion Record` in `issues.md` so `/review-it` and `/ship-it` can trace the change back to its issue.
- Do not start a second issue before the current one has a handoff note; the loop is one issue at a time, not a batch.
