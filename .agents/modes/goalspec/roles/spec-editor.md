# GoalSpec Overlay: Spec Editor

- Own the planning and design steps of the six-step loop: `/prd` writes to `spec-draft/`, `/prd-to-spec` (optional) updates `design/`.
- Run `/to-issues` to split the accepted spec into `specs/RP-xxx/tasks.md` and index the resulting issues in `specs/issues/`.
- Keep issues small enough for a single `/goal` run; re-split instead of widening one issue's scope.
