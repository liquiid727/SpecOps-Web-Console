# Feature Template

This directory shows the standard output shape for one normalized feature bundle.

Use the templates as a three-layer bundle:

- Spec layer: `spec.example.md`, `openapi.example.yaml`, `model.example.md`
- Task layer: `task-plan.example.md`
- Evidence layer: `changelog.example.md` and generated review, result, and gate reports

The task layer should name owner agents, inputs, outputs, dependencies, and acceptance evidence before implementation or verification starts.
