# Agent Governance Reuse Pack Routing

Projects importing this pack should read the following files in order:

1. `agent-teams/agent-governance-reuse-pack/nnaccel_ai/registry.yaml`
2. `agent-teams/agent-governance-reuse-pack/nnaccel_ai/catalogs/roles.yaml`
3. `agent-teams/agent-governance-reuse-pack/nnaccel_ai/catalogs/model-routing.yaml`
4. `agent-teams/agent-governance-reuse-pack/nnaccel_ai/openspec/specs/agent-team-governance/agent-team-governance.yaml`

This pack is namespaced on purpose. Importing it does not activate it automatically for the target project root.
