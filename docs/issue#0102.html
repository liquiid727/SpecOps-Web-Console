Implementation Notes

Issue #0102 — Execution history, transcript recovery, and redaction — 2026-08-05

Design Decisions

Durable history is authoritative

History APIs and restart recovery read ExecutionRepository fold results. Transient WebSocket frames are projections only.

Safe restart confirmation

A persisted awaiting-confirmation task whose in-memory run context is unavailable returns ROUTE_REPLAY_CONFIRMATION_REQUIRED without changing state or executing a retry.

Non-secret Transcript projection

Completed routed execution appends lifecycle/progress summaries containing stable IDs, ordinal, trigger, and states; prompts, error messages, environment, and credentials are excluded.

Deviations

Complete final JSON without newline is accepted

A syntactically and schema-valid final JSONL record is recovered even without a trailing newline; only a syntactically truncated tail is ignored.

Tradeoffs

Local acceptance with explicit waivers

In-process queueing and deterministic fixtures provide strong local evidence while cross-process locking/fsync, real external engines, packaging, and browser behavior remain unclaimed.

Open Questions

Broaden summary matrix

Add independent failed, automatic-fallback, and multi-Attempt Transcript-summary scenarios before removing the local waiver.
