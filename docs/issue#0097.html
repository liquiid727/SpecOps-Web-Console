Implementation Notes

Issue #0097 — Route bindings, preflight, and one-shot override API — 2026-08-05

Design Decisions

Preflight precedes all send side effects

Route resolution, fixed-target validation, candidate eligibility, and engine compatibility complete before transcript user messages, Tasks, Attempts, runtime/PTY, Agent, or state-save side effects.

One-shot stays request-local

The fixed Deployment override is carried only through the current request and resolved execution snapshot; it is never written to Session, AppState, or reused by the next request.

Deviations

Local seam evidence

Tests use deterministic HTTP fixtures, fake runtime seams, a JSON execution repository fixture, and synthetic SecretStore canaries. They do not claim real external engine or packaged behavior.

Tradeoffs

Legacy compatibility remains explicit

No-route chat and terminal sessions continue through the legacy model path and expose no fake Deployment identity while routed sessions use the shared resolver.

Open Questions

Execution lifecycle

Attempt, fallback, retry, and runtime scheduling remain issues 098–102. Packaged-host, cross-process, external-engine, and browser behavior are outside this local gate.
