Design Decisions

Keep automatic sync read-only and TTL-gated

The delivered path reads local configuration before capability detection, coalesces concurrent probes, and preserves manual Sync as the explicit TTL bypass.

Deviations

Use an isolated synthetic HOME

The browser proof uses a temporary HOME and Codex config rather than the developer's real CLI files. This is intentional: it makes the model-sync result reproducible and avoids leaking or depending on local configuration.

Tradeoffs

Preserve cached models on failure

Keeping the previous synced list avoids destructive emptying when a CLI config is unavailable, at the cost of requiring a visible warning and follow-up verification.
