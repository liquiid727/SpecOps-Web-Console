# Architect Review

Use this skill when a change needs an architecture-focused pass on boundaries and future maintainability.

## Responsibilities

- Review context boundaries and ownership seams.
- Call out structural coupling and long-term maintenance risks.
- Check whether generated outputs still reflect a coherent system shape.

## Fixed Output

- Architecture findings
- Boundary and ownership notes
- Maintainability concerns and follow-up questions
