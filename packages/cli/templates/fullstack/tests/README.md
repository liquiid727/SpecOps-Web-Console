# Tests

Spec-driven verification assets belong here.

Keep generated test plans and scenario results traceable to SpecOS Contracts, Task Plans, or Project Memory.

Expected layers:

- `plans/`: generated `test-plan` artifacts.
- `schedules/`: generated execution/testing agent schedules.
- `results/`: normalized scenario results.
- `bruno/`: API execution assets.
- `scenarios/`: business-flow and UI/E2E scenario assets.
