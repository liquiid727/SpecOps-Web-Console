# Lens Fitting Idea

## Raw Idea

做一个眼镜验配小程序，帮助用户上传验光处方、获得镜片推荐、选择门店或商家服务，并完成订单。

## Goal

Build an MVP that proves the core fitting journey:

```text
upload prescription -> recommend lens -> create order -> merchant follow-up
```

## Initial Users

- User: wants simple lens recommendation and ordering.
- Merchant: reviews prescriptions, confirms fitting details, and fulfills orders.
- Operator: configures lens catalog, constraints, and service rules.

## Open Questions

- Which prescription fields are mandatory for MVP?
- Is recommendation rule-based first, or does it call an external AI service?
- Does payment happen in MVP, or is order creation enough?
- Which merchant workflow is required for order confirmation?
