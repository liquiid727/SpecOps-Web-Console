# Product Spec

## Product

Lens Fitting MVP is an eyewear fitting mini program / SaaS starter.

## Actors

- User: uploads prescription and creates an order.
- Merchant: reviews order and follows up.
- Operator: configures catalog, recommendation rules, and service constraints.

## Core Flows

1. `upload_prescription`
2. `recommend_lens`
3. `create_order`
4. `merchant_review`

## Acceptance

- A user can move from prescription input to a created order.
- The merchant can identify orders that require review.
- Open domain questions stay visible before promotion.
