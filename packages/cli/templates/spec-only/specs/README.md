# SpecOS Knowledge Spine

SpecOS organizes project knowledge as:

- `current/`: Project Memory, the accepted baseline.
- `changes/`: Change Workspaces for active deltas.
- `archive/`: Evidence Archive for completed work.

SpecOS changes flow through three layers:

```text
spec layer -> task layer -> evidence layer
```

- Spec layer: durable project memory, drafts, active change contracts, rules, and open questions.
- Task layer: `task-plan.md`, `execution-plan.md`, test schedules, owner agents, inputs, outputs, dependencies, and required evidence.
- Evidence layer: implementation reports, normalized test results, gate reports, review reports, changelogs, promotion notes, and archive records.
