# Current

`current/` is the active delivery workspace.

Keep it small and role-oriented.

Recommended `LiteSpec` files:

```text
current/
  project-status.md
  active-feature.md
  active-context.md
  active-tasks.md
  blockers.md
  handoff.md
```

Recommended `EnterpriseSpec` files:

```text
current/
  release-status.md
  sprint-status.md
  active-feature.md
  blockers.md
  decisions.md
  handoff.md
```
