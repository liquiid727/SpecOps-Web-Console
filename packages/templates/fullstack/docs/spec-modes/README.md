# Spec Modes

This project supports two documented operating modes:

- `LiteSpec`: the default, feature-driven, low-token mode
- `EnterpriseSpec`: the governed, delivery-driven mode

Start from `LiteSpec` unless QA, audit, release governance, or multi-team delivery requires `EnterpriseSpec`.

- `docs/spec-modes/LiteSpec/README.md`
- `docs/spec-modes/EnterpriseSpec/README.md`
