# Proposed Changes

Proposed SpecOS changes belong here before they are accepted into `specs/current/`.

Each change should keep spec, task, and evidence artifacts together:

```text
specs/changes/<change-id>/
  spec.md
  architecture-review.md
  design-review.md
  task-plan.md
  execution-plan.md
  test-strategy.md
  review-report.md
  changelog.md
  workflow-state.json
```

`task-plan.md` is the bridge between spec intent and evidence. It should name task ids, owner agents, inputs, outputs, dependencies, status, and acceptance evidence.
